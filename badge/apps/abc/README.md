# ABC

ABC is a picture alphabet for toddlers that shows one big letter, a picture and its word on each screen.

## Usage

Each screen shows the uppercase and lowercase letter ("A a"), a picture and
the word ("Apple") with its first letter highlighted. The background colour
changes with every letter.

- **RIGHT**: next letter (Z wraps back to A).
- **LEFT**: previous letter (A wraps round to Z).
- **SELECT** or **UP**: the picture jumps.
- **DOWN**: the picture squishes.
- **BACK** or **MENU**: the picture wiggles.
- **HOME** returns to the badge menu, as in every app. Little fingers may
  touch it by accident; just open ABC again.

No button ever leaves a toddler on a confusing screen: there are no menus,
nothing to win or lose, and every play pad does something friendly. The
letter you were on is remembered the next time ABC opens. The badge has no
speaker, so grown-ups say the letters and words; the case lights glow softly
when the letter changes.

Words: Apple, Ball, Cat, Dog, Elephant, Fish, Goat, Horse, Ink pen, Juice,
Kite, Lion, Monkey, Nose, Oranges, Pig, Queen, Rabbit, Sun, Tree, Umbrella,
Violin, Watch, Xylophone, Yo-yo, Zebra.

## Hardware

Uses the screen, touch pads and case lights only. No Wi-Fi or `secrets.py`
needed. If a picture file is missing, the letter and word are still shown.

Always supervise play: the badge is small, has a battery, and the lanyard is
not a toy.
